# 👋 Backend Developer Portfolio

안녕하세요.

문제가 발생했을 때 단순히 기능을 수정하는 것이 아니라 **로그와 데이터 흐름을 분석하여 구조적으로 해결하는 백엔드 개발자**를 목표로 하고 있습니다.

Java/Spring Boot 기반 백엔드 개발과 WebRTC 기반 실시간 서비스 개발을 경험했으며, 인증/인가, 실시간 데이터 처리, 외부 시스템 연동 과정에서 발생한 문제를 해결하며 개발 역량을 쌓았습니다.

이 저장소는 프로젝트를 단순히 소개하는 것이 아니라,

- 프로젝트를 설계한 과정
- 기술 선택 이유
- 문제 해결 과정
- 아키텍처
- 개발하면서 배운 점

을 정리한 기술 문서입니다.

# 📌 What I Focus On

프로젝트를 진행하면서 가장 중요하게 생각하는 것은 **"왜 이렇게 설계했는가"** 입니다.

기능 구현보다

- 구조 설계
- 데이터 흐름
- 인증 흐름
- 네트워크 환경
- 장애 원인 분석

을 먼저 고민하며 개발하려고 노력합니다.

실시간 서비스에서는 STT Streaming 구조를 개선하여 서버 비용을 절감했고,

인증 시스템에서는 Spring Security와 JWT 기반 인증 구조를 구현하며 인증 흐름을 이해했습니다.

또한 프로젝트를 진행하며 발생한 문제를 로그와 예외 분석을 통해 해결하는 경험을 반복하며 문제 해결 역량을 키워왔습니다.
